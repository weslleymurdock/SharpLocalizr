# Feature Vertical Slice

Use `docs/skills/feature-vertical-slice.md` as the authoritative project-specific workflow. Inspect an existing feature first, keep controllers thin, keep handlers thin, put use-case logic in services, and keep infrastructure behind Application abstractions.
